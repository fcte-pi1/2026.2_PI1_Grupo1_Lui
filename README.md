# Projeto Integrador 1 - 2026.2 | Grupo 01 | Prof. Lui

![Calendário 2026/2](https://github.com/fcte-pi1/template/blob/main/docs/figs/Calendario.png?raw=true)

> **Aviso ao Professor:** Este é o repositório oficial que o **Grupo 01** está utilizando para o desenvolvimento do projeto de PI1 durante o semestre **2026.2**, sob a orientação do **Prof. Lui**.

Este repositório serve para organizar e armazenar todos os artefatos do nosso projeto. Ele é dividido em pastas, onde cada parte do trabalho deve ser guardada. Os arquivos a serem armazenados incluem documentação, código-fonte, arquivos de CAD, esquemáticos, arquivos de simulação de circuitos e dados.

A organização e a correta utilização do repositório do projeto serão considerados na avaliação do grupo. Dessa forma, é fundamental que *todos os membros* do grupo utilizem o `git` de forma alinhada com a estratégia definida pela equipe. Faremos o uso ativo das ferramentas que o GitHub oferece, incluindo _branches_, Pull Requests (PRs), revisões, _issues_ e quadros de projeto.

Lembrem sempre de evitar enviar arquivos muito grandes (>5MB). No caso de vídeos e outros arquivos pesados que sejam necessários, o arquivo deve ser armazenado em outra plataforma (como Google Drive ou YouTube) e apenas o _link_ deve ser disponibilizado no repositório.

> [!IMPORTANTE]
> A estrutura de pastas do projeto não reflete a divisão de equipes. Os membros podem e devem trabalhar nas diferentes pastas a depender da necessidade do projeto e das tarefas alocadas.
